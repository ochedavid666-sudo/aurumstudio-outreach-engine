# Aurum OS

A self-owned outbound acquisition system designed to help service businesses generate clients without relying on expensive SaaS platforms.

## Current Modules

### Lead Database

* fresh_leads.csv
* verified prospect storage

### Outreach Engine

* Multi-mailbox rotation
* Zoho SMTP integration
* Infomaniak SMTP integration
* Daily sending limits
* Personalized outreach

### CRM Layer

* sent_leads.csv
* replied_leads.csv
* lead state management

### Automation Layer

* SMTP testing
* Mailbox rotation
* Logging system

## Upcoming Features

* Reply detection
* Telegram notifications
* Automated follow-ups
* WhatsApp nurturing
* Dashboard
* AI personalization

## Goal

Build a self-owned acquisition operating system capable of generating international clients while maintaining low operating costs.
